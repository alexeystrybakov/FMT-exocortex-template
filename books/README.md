# Каталог книг (books)

В этой папке хранятся электронные книги, относящиеся к вашей библиотеке.

## Оглавление

- [ ] Добавьте сюда список книг с краткими аннотациями. Пример:

| Файл | Автор | Год | Описание |
|------|-------|-----|----------|
| Thinking_Fast_and_Slow_Kahneman.pdf | Даниэль Канеман | 2011 | Классика по психологии мышления |
| Clean_Code_Martin.pdf | Роберт Мартин | 2008 | Практика написания чистого кода |

## Рекомендации по добавлению

- Используйте понятные и единообразные имена файлов: `Название_Автор.pdf`
- Для каждой книги добавляйте строку в таблицу выше.
- При необходимости создавайте подпапки по жанрам или тематикам.
